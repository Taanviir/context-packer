Benchmark

Jev finds more of the files a commit changed.

Each task is a real commit subject. The answer is the source files that commit modified, and every file is read as it was before the commit, so the answer can't leak in. Choices were made on 10 dev tasks per repo; the numbers below are the 30 held-out test tasks per repo, run once.

Recall@10 by repository

Recall@10 is the share of a commit's changed files that appear in the top ten. Jev ran on four repositories; the two smallest also have keyword and local Laya runs.

How sure is the difference?

Each bar is the mean per-task difference, with a 95% paired bootstrap interval (10,000 resamples, fixed seed). An interval that crosses zero means the repo alone can't separate the two.

Recall as the list gets longer

Pooled over the 120 test tasks. The gap is widest at five files, where a short list matters most to an agent.

Cost and time per pack

Times are wall-clock for ranking files already in memory, from uncached runs. Cost is Jev's reported input tokens at $0.042 per million. Failed batches are Jev calls that returned an error; their files scored zero for that pass and the pack went on.

Method and limits

  • Repositories are pinned to a commit: hono (TypeScript), rich (Python), gin (Go), prometheus (Go and TypeScript), httpx (Python), ripgrep (Rust).
  • Tasks: non-merge commits whose subject has at least four words, that modify one to five existing source files and add, delete or move none. Commits named like chores, releases, docs or refactors are skipped. Conventional-commit prefixes and PR numbers are stripped from the task text.
  • Split: a fixed hash order over eligible commits; the first 10 are dev, the next 30 test.
  • Commit subjects are short and often vaguer than a real request to an agent. File recall is also not task success: this benchmark doesn't measure whether an agent then makes the right change.
  • The whole run, including the rejected sketcher, billed 47 million Jev input tokens, about $2.

Browse every task and both rankings in the run explorer.

Everything is reproducible from the repository: bench/mine.ts freezes the tasks, bench/run.ts runs a provider, and bench/report.ts writes the summary this page draws from. Jev responses are cached by request, so a replay is free.
