Benchmark

Jev finds more of the files a change needs.

Each test is a real past change from an open-source project: its commit message is the task, and the files it changed are the right answer. The tool sees the project as it was before the change, so it can't cheat. The score is simple: of the files the change really needed, how many did the tool put in its top 10?

Plain keyword search finds 69 of every 100 needed files. Jev finds 78. Laya, the local model, found fewer than keyword search.

Project by project

Thirty tests per project. Jev ran on the four projects on top; Laya ran on gin and httpx, and the two smallest projects have keyword search only.

Is the difference real or luck?

With 30 tests per project, some difference would show up by chance alone. The line around each dot is the range the true difference plausibly sits in (a 95% bootstrap interval). When the whole line is right of zero, the gain is real; when it crosses zero, that project alone can't tell.

Across all four projects, Jev finds 9 more needed files per 100 than keyword search, somewhere between 4 and 15. Rewriting the file summaries for each language changed nothing. Laya finds about 6 fewer than keyword search, between 2 and 11 fewer.

Top 5, 10 and 20

The gap is widest when the list is shortest. In the top five, Jev finds 69% of needed files and keyword search 56%.

Cost and time

Per test, from runs that weren't served from a cache. Jev's cost is its reported input tokens at $0.042 per million. Keyword search and Laya cost nothing but your CPU. Failed requests are Jev calls that returned an error; those files scored zero for that step and the ranking went on.

Method and limits

  • Repositories are pinned to a commit: hono (TypeScript), rich (Python), gin (Go), prometheus (Go and TypeScript), httpx (Python), ripgrep (Rust).
  • Tasks: non-merge commits whose subject has at least four words, that modify one to five existing source files and add, delete or move none. Commits named like chores, releases, docs or refactors are skipped. Conventional-commit prefixes and PR numbers are stripped from the task text.
  • Split: a fixed order over eligible commits; the first 10 per project were used to make decisions, and the next 30 are the tests reported here, run once.
  • Commit messages are short and often vaguer than a real request to an agent. Finding the right files is also not the same as making the right change; this benchmark measures only the first.
  • The whole run, including the rejected sketcher, billed 47 million Jev input tokens, about $2.

Browse every task and both rankings in the run explorer.

Everything is reproducible from the repository: bench/mine.ts freezes the tasks, bench/run.ts runs a provider, and bench/report.ts writes the summary this page draws from. Jev responses are cached by request, so a replay is free.
